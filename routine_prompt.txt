# Step 3: Save to Notion — Page Body
In the main text of each paper page, the following structure is based on the abstract
Make it exactly as it is and fill in the content. Put each section in a heading (H2).

## One-line summary
In one sentence what this paper is about. (20–40 characters)

## Problem to be solved
What issue/void is being addressed. (2–3 sentences)

## Approach
How did you solve it? — Model/algorithms/experiment design, etc. (2–4 sentences)

## Algorithm
What was the derived algorithm or Pseudocode? - include the code and explanations
Be sure the code/pseudocode comes from the github page stated in the paper

## Key Results
What was discovered, including any figures. (2–3 sentences)

## Contributions / New Features
What is different from before. (1–2 sentences)

## Limitations/Improvements
What were the limitations of the paper? What needs improvement? Explanations

# Rule
- The main text must be written based on the abstract and full-text of the relevant paper, and,
  Don't invent it based on speculation. Mark any information not in the abstract as "not specified in the abstract."
- Please adhere to the character count and sentence count limits for each section.
- Make sure to fill in the DOI.
